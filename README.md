# Приложение с расписанием SZIU RANEPA

Приложение с расписанием, для просмотра пар в более удобном формате.

# Предупреждение
### Данное приложение (как и телеграмм бот) было созданно Шилиным Артуром и прямого отношения к администрации факультета и вуза не несёт. По всем вопросам в личные сообщения в [телеграмм](https://t.me/zuKLee).

## Описание

Данное приложение созданно с целью облегчить просмотр расписания. А так же даёт возможность просматривать расписание без интернета и с более красивым интерфесом.

## Установка
### Android

Выбор версии приложения зависит только от разрядности вашей системы.
Попробуйте установить для начала версию которая начинается на [app-64bit](https://github.com/Taimpix/schedule_app/releases/download/alpha/app-64bit-v26.02.alpha.1.apk) если она у вас не заработает, то установите версию [app-32bit](https://github.com/Taimpix/schedule_app/releases/download/alpha/app-32bit-v26.02.alpha.1.apk) и всё, приятного использования.

### iOS

Для установки приложения на iOS вам потребуется ноутбук или ПК
1) Установите на ваш ПК/ноутбук приложение [AltServer](https://altstore.io/#:~:text=AltStore%20Classic) (AltStore Classic).
2) Установите с официальных сайтов [iTunes](https://www.apple.com/itunes/) и [iCloud](https://updates.cdn-apple.com/2020/windows/001-39935-20200911-1A70AA56-F448-11EA-8CC0-99D41950005E/iCloudSetup.exe) (Устанавливать не с Microsoft Store).
3) Подключите ваше устройство через провод к ПК/ноутбуку и разблокируйте его.
4) Откройте iTunes и в настройках включите синхронизацию по Wi-Fi.
5) В панели задач выберите иконку ALtServer -> Install AltStore -> выберите ваше устройство -> войдите в свой аккаунт AppleID
6) На вашем устройстве откройте Найстройки -> Основные -> VPN и управление устройством -> ПО разработчика -> Доверять
7) Скачайте на ваше устройство [установочный файл](https://github.com/Taimpix/schedule_app/releases/download/alpha/app-ios-v26.02.alpha.1.ipa) нажмите поделиться и выберете AltStore, подождите пока приложение установиться.
8) Приложение можно использовать, но раз в неделю нужно подписывать занаво через приложение AltStore
